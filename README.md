## Why GitHub Flow
- main은 항상 배포 가능한 상태여야 하고, feature 브랜치가 이를 보호해주기 때문
- 작업을 브랜치로 격리하면 충돌 범위가 좁아지고, 문제가 생겨도 되돌리기 쉬움
- PR 기반 리뷰를 거치므로 품질과 변경 이력의 추적성이 확보됨
